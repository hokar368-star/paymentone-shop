# 🤖 فروشگاه اکانت‌های هوش مصنوعی

فروشگاه آنلاین استاتیک برای فروش اکانت‌های پریمیوم AI با ادغام **Payment One**

## ✨ ویژگی‌ها

- ✅ صفحه محصول پویا و زیبا
- ✅ سبد خرید با ذخیره‌سازی محلی (LocalStorage)
- ✅ سیستم پرداخت Payment One
- ✅ طراحی واکنش‌پذیر (Responsive Design)
- ✅ رابط کاربری فارسی
- ✅ بدون نیاز به Backend

## 🚀 نحوه استفاده

### 1. GitHub Pages فعال کنید

```
روی مخزن → Settings → Pages
Source: Deploy from a branch
Branch: main / root
Save کنید
```

### 2. سایت را باز کنید

```
https://hokar368-star.github.io/paymentone-shop/
```

## 📁 ساختار فایل‌ها

```
paymentone-shop/
├── index.html          # صفحه اصلی
├── styles.css          # استایل‌ها
├── products.js         # لیست محصولات
├── cart.js             # منطق سبد خرید
├── payment.js          # ادغام Payment One
└── README.md           # این فایل
```

## 💳 ادغام Payment One

برای ادغام واقعی Payment One:

1. حساب Payment One بسازید
2. API Key خود را دریافت کنید
3. فایل `payment.js` را ویرایش کنید و API Key را جایگزین کنید

## 📝 نحوه اضافه کردن محصول جدید
